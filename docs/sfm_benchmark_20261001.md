# 2026-10-01 SfM 实测与优化

本轮比较 Colite 当前 CUDA SIFT / BF 路径与本机 COLMAP 4.0 CUDA 构建，涵盖特征提取、穷举匹配、增量稀疏构建和独立 BA。完整原始数据保存于 `output/sfm_quality_20261001/`，最终稳定实现对应 `gpu_validated/`。此前 `gpu_final/` 和 `gpu_periodic/` 是未采用的实验，不能作为当前实现的结果。

## 测试约定

- WSL Ubuntu 22.04，RTX 4070 SUPER 12 GB，CUDA 13.2，20 个逻辑 CPU。两端 Release 构建，逐阶段串行运行。
- Building：18 张 3072×2304 JPEG；House：36 张 4592×3056 JPEG。全分辨率、单个共享 SIMPLE_RADIAL 相机、特征预算 8192、提取线程 8、穷举匹配、guided matching。
- 2026-10-18 核对修正：下述“全分辨率”只准确描述原始图像和当时 Colite。脚本给 COLMAP 传 max_image_size=-1，实际 SIFT 自动限为 3200；House 的两端提取尺寸并不一致。因此历史独立前端表不能作为同尺寸提取吞吐比较。共用描述子/verified 输入的控制实验不受此问题影响。
- 独立前端：Colite `cuda_vlfeat`，COLMAP GPU SIFT。两者不是相同提取器；相同预算也不是相同输出数量，COLMAP 保留多个主方向，Colite CUDA 路径按响应截断到预算。因此速度与覆盖率必须一起比较。
- 控制前端：直接导入 COLMAP 数据库的 keypoints、descriptors、verified matches、relative poses；pair angle 只由数据库相对位姿与观测推导，不使用最终模型位姿。先测试 Colite mapper，再重跑 Colite matching 与数据库逐对比较。
- 独立 BA：两端读取相同参考模型，使用固定随机种子的轻微点/平移扰动，相同 50 次最大迭代限制。生产默认损失函数不同：Colite 的鲁棒损失与 COLMAP 的普通平方损失；不是求解器逐位一致测试。
- 时间是含进程启动、工作区读写的墙钟时间，不计缓存命中。最终 GPU 表中的 COLMAP 前端时间复用初次实测，原路径在 `reference_run` 中明示；不是与每次 Colite 运行同时重新测量。
- 质量按最终相机参数逐条重算观测误差，并报告注册数、点数、观测数、track 长度、P95/P99、超过 4 px 的观测和相机后方点。COLMAP 是参考结果，不是真值；低重投影误差、更多点或匹配集合一致都不能单独证明真实精度更高。

## 本轮保留的优化

1. JPEG EXIF 改为流式扫描 APP1，读取尺寸使用 SOF 头，避免相机设置阶段反复读取整个压缩文件和解码图像。普通方向图像取消多余 clone；保持 EXIF 方向与尺寸语义。
2. CUDA BF 的行最佳/次佳归约改为每 warp 扫描一行，连续读取 dot matrix，并稳定处理并列分数、跨 warp 范围与不足 32 个特征的情况。
3. verified matches TSV 按 pair 复用几何字符串，读取改为逐行与相同前缀复用，减少重复格式化、解析及整文件常驻内存。
4. BA 小模型采用 DENSE_SCHUR；小残差问题使用单线程，较大问题保留并行，减少小规模求解的调度成本。
5. 最终 BA 和 track merge 后再执行观测/点过滤，确保保存结果符合既定误差阈值。之前 Building / House 独立结果分别残留 12 / 329 条超过 4 px 的观测，共用前端 House 残留 1000 条；最终稳定结果均为零。

## GPU 最终结果

单位为秒，每格为 Colite / COLMAP；前端使用双方各自提取的特征。

| 数据集 | 提取 | 匹配与几何验证 | 稀疏构建 | 三阶段总时间 |
|---|---:|---:|---:|---:|
| Building | 2.82 / 8.64 | 3.58 / 2.82 | 15.50 / 12.81 | 21.91 / 24.27 |
| House | 13.45 / 20.69 | 7.28 / 7.71 | 22.32 / 48.18 | 43.05 / 76.58 |

提取较本轮优化前 Building 9.47 秒、House 53.69 秒分别缩短约 70% / 75%。这主要修复了图像读取开销，不能归因于 SIFT 算法本身超过 COLMAP。独立前端总时间较优化前 30.79 / 82.37 秒降至 21.91 / 43.05 秒。

| 独立结果 | 注册数 | 点数 | 观测数 | 平均 track | 平均误差 / P95，px |
|---|---:|---:|---:|---:|---:|
| Building Colite | 18 | 15,727 | 69,300 | 4.406 | 0.388 / 1.105 |
| Building COLMAP | 18 | 18,765 | 81,110 | 4.322 | 0.609 / 1.789 |
| House Colite | 36 | 19,426 | 82,728 | 4.259 | 0.969 / 2.652 |
| House COLMAP | 36 | 40,034 | 149,540 | 3.735 | 1.247 / 2.843 |

两端最终稀疏模型的超过 4 px 观测、相机后方观测均为零。Colite 独立结果更稀疏：Building 点数约少 16%，House 约少 51%；不能据更低的自重投影误差宣布质量优于参考。House 仅 250 个有效 verified pair，对比 COLMAP 494；实际提取特征数为 294,912 / 368,100，原始匹配数为 71,907 / 202,850，说明还存在特征与关联覆盖差距。

## 共用输入隔离结果

| 数据集 | mapper 时间，Colite / COLMAP | 点数，Colite / COLMAP | 平均误差，Colite / COLMAP，px | 旋转均值差 | 中心均值差 / 最大基线 |
|---|---:|---:|---:|---:|---:|
| Building | 17.57 / 12.81 | 18,937 / 18,765 | 0.627 / 0.609 | 0.0558° | 0.0131% |
| House | 56.69 / 48.18 | 40,539 / 40,034 | 1.327 / 1.247 | 0.0552° | 0.0314% |

共用前端后，两端注册数相同，点数差小于 1.3%，相机位姿很接近。Colite mapper 耗时约高 37% / 18%，误差均值约高 3% / 6%；House P95 为 3.105 / 2.843 px。稀疏构建具备接近的几何水平，但效率和误差尾部尚有明确改进空间。

共用描述子重跑完整 matching：Building 7.85 / 2.82 秒，House 26.56 / 7.71 秒，Colite 慢约 2.8 / 3.4 倍。原始 BF 匹配 Building 153/153 pair 完全一致；House 629/630 pair 完全一致，COLMAP 的 202,850 对全部保留，额外 13 对，集合 Jaccard 为 99.9936%。这验证了匹配语义基本一致，也说明独立前端较快的匹配时间不能作为相同负载效率相当的证据。

几何验证后的匹配集合 Jaccard 仅 71.13% / 67.76%，计数为 Building 179,575 / 163,305、House 345,061 / 351,693。模型估计、退化分类和引导搜索还未逐对等价；这些集合指标仅衡量一致性，不能解释为真实匹配精确率。应结合公共模型结果与后续真值/人工抽样检验判断质量。

## 独立 BA 隔离结果

| 数据集 | BA 时间，Colite / COLMAP | 初始平均误差，px | 最终平均误差，Colite / COLMAP，px | 最终 RMSE，Colite / COLMAP，px |
|---|---:|---:|---:|---:|
| Building | 1.56 / 1.43 | 4.061 | 0.606 / 0.609 | 0.82657 / 0.82611 |
| House | 2.83 / 2.58 | 3.940 | 1.239 / 1.247 | 1.49252 / 1.49152 |

此受控输入下 BA 已接近参考的收敛水平，时间约高 9% / 10%，不能据单次计时判定显著性能差距。Colite 鲁棒损失的误差均值略低而 RMSE 略高。独立 `bundle_adjuster` 不执行 mapper 的最终观测过滤，因而可以保留少量超过 4 px 的观测；其目标是优化相同观测，而不是删点后比较残差。

## CPU Building 补充验证

两端 VLFeat 路径、8192 基础特征预算、8 个提取线程、CPU BF、guided matching。结果保存于 `cpu/report.json`；匹配使用各自默认自动线程预算。

| 阶段 | Colite，秒 | COLMAP，秒 |
|---|---:|---:|
| 特征提取 | 20.70 | 36.20 |
| 独立前端匹配与几何验证 | 43.65 | 747.74 |
| 独立前端 mapper | 28.07 | 18.64 |
| 独立前端总时间 | 92.42 | 802.58 |
| 共用描述子完整匹配 | 45.78 | 747.74 |
| 共用几何 mapper | 26.24 | 18.64 |
| 共用扰动输入 BA | 2.09 | 2.11 |

实际特征数量 260,310 / 264,396，独立前端均注册 18 张，点数 27,750 / 25,001，平均误差 0.568 / 0.600 px，P95 为 1.585 / 1.761 px，超过 4 px 的观测均为零。相同描述子的原始 BF 匹配 153/153 pair 完全相同，223,076 对逐条一致；完整匹配在该配置约快 16.3 倍，几何验证后集合 Jaccard 为 70.20%。因此本轮 CPU 结果已达到较好的速度与几何代理质量水平，但不能据此宣称 GPU 同样领先或有真值精度优势。

共用几何的 mapper 点数 25,129 / 25,001，平均误差 0.609 / 0.600 px，但 Colite 耗时高约 41%，与 GPU 控制结果一致地指向稀疏构建调度效率问题。独立 BA 从平均误差 4.036 px 收敛到 0.5966 / 0.5995 px，RMSE 为 0.81380 / 0.81331 px，耗时接近。

## 后续优先级

1. **P0：相同特征负载的 GPU 完整 matching 吞吐。** 分开计时原始 GPU BF、F/E/H 估计、guided matching、相对位姿和 TSV I/O，首先优化受控输入慢 2.8–3.4 倍的阶段；当前 warp/IO 改动只带来有限改善，还没有消除差距。CPU 与 GPU 结论需要分开。
2. **P0：GPU SIFT 覆盖与特征预算语义。** 对齐多主方向保留策略，并比较尺度/空间分布、重复率和有效 pair；在相同输出特征量下复测，避免仅提高 ratio 导致短 track、坏模型合并和耗时膨胀。House 缺少一半点是当前独立前端最显著的质量代理差距。
3. **P1：受控 mapper 的耗时与误差尾部。** 汇总所有子模型的注册、三角化、局部 BA、track 完成/合并耗时；改善最终 BA 与过滤/重三角化调度。周期 BA 需先解决合并模型初始几何导致的求解失败，再通过完整 House 回归后启用。
4. **P1：更完整的验证。** 至少三次重复、长序列/弱纹理/环路数据和带真值数据；加入真实匹配抽样精度与共同可见区域覆盖指标。不得把这两个小图集结论扩展为所有 SfM 场景。

## 未采用的实验

将独立 matcher 的 guided ratio 从 0.8 放宽到 0.95 会增加 House 覆盖，但显著增加构建耗时，也增加短 track 和误差尾部，不能视为无代价的质量优化。本轮保持独立 matcher 默认 0.8；历史 `recon_sfm` 默认 0.95 保留，需按其真实配置单独评估。

使用 inlier 数与三角化角联合排序初始化 pair，在 House 只注册了 35/36 张，已撤回。按 1.1 倍模型增长周期触发全局 BA 的实验在 House 合并模型上遇到 Ceres 初始 residual/Jacobian 评估失败，也已撤回；最终代码不接受这两个未验证的增长参数。失败日志和非零退出码保留于 `gpu_periodic/house/colite/mapper/`，不能通过合成单测通过就认定该策略可用。

## 复现

在仓库根目录的 WSL 中执行；脚本要求全新输出目录，记录完整 argv、退出码、资源和日志、二进制 SHA256。`--resume` 仅用于相同二进制恢复已成功阶段。需要 numpy。

```bash
python3 scripts/benchmark_sfm.py \
  --output output/sfm_quality_new/gpu \
  --device gpu --colite-guided-ratio 0.8

python3 scripts/benchmark_sfm.py \
  --output output/sfm_quality_new/cpu \
  --device cpu --datasets building-18
```

正式性能回归应至少重复三次，报告中位数；本轮是工程诊断与优化验证，单次小幅耗时差异不作确定性优势结论。ALIKED/LightGlue、大规模图集和真值精度评估不在本轮覆盖范围。
